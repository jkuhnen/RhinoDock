# Rhino VS Bridge v0.4.0

Rhino VS Bridge v0.4.0 is the first stable installable release. It connects
Visual Studio 2026 to Rhino 8 through McNeel's official RhinoCode CLI, while
keeping editing and IntelliSense in Visual Studio's Python tooling.

## Highlights

- Save and run the active Rhino CPython script with **Shift+F2**.
- Stream stdout, stderr, tracebacks, and completion diagnostics to the
  **Rhino VS Bridge** Output pane.
- Navigate Python runtime errors through Visual Studio's native Error List,
  including nested frames and source files outside the solution.
- Select the intended Rhino process explicitly when multiple instances are
  running, with no fallback to a different instance.
- Configure PTVS/Pylance search paths from Rhino-generated type stubs without
  replacing existing project paths.
- Request cooperative cancellation and safely prevent overlapping execution.
- Detect delayed Rhino-side startup, recover from CLI launch failures, and
  automatically reconcile verified late completion after a startup timeout.

## Verified environment

The complete workflow passed real-world GUI testing with Visual Studio 2026
and Rhino 8.36. Automated coverage includes 31 C# tests and 17 Python tests,
plus Debug and Release builds of the VSIX.

## Installation

Download `RhinoVSBridge-v0.4.0.vsix`, close Visual Studio, and double-click the
file to install it into a normal 64-bit Visual Studio 2026 instance. The Python
development workload, .NET Framework 4.8, and Rhino 8.11 or newer are required.
Then start Rhino's **StartScriptServer** command before running scripts.

See the [complete installation and usage guide](../installation-v040.md) for
IntelliSense setup, execution, Output-pane diagnostics, and Error List
navigation.

## Known limitations

- Restart the solution after configuring IntelliSense so Pylance reloads the
  generated search paths.
- Cancellation is cooperative; blocking native calls can delay it.
- `.py2` lacks the CPython runner's structured output, cancellation, and Error
  List guarantees.
- The Output-pane traceback is preserved as text; navigation uses Error List.
- Interactive breakpoint debugging and `debugpy` integration are not included.
- The release VSIX is not yet cryptographically signed. Verify the accompanying
  SHA-256 checksum before manual installation.
